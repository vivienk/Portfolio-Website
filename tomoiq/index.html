Overview
TomoAI/TomoIQ is an experimental concept designed to make credit education approachable through conversational, AI-driven explainability. I led the vision and UX design to help users understand credit decisions and score changes in plain language — turning confusion into confidence.

Problem
Financial literacy gaps made users rely on customer support to interpret credit score changes. We needed a scalable, friendly, human-centered solution that could provide personalized insights without overwhelming users with financial jargon.


Process

  1. Vision Definition

  • Shaped the product vision and user value proposition for a credit-building AI assistant that communicates in friendly, human terms.

Overview
TomoAI/TomoIQ is an experimental concept designed to make credit education approachable through conversational, AI-driven explainability. I led the vision and UX design to help users understand credit decisions and score changes in plain language — turning confusion into confidence.

Problem
Financial literacy gaps made users rely on customer support to interpret credit score changes. We needed a scalable, friendly, human-centered solution that could provide personalized insights without overwhelming users with financial jargon.


Process

  1. Vision Definition

  • Shaped the product vision and user value proposition for a credit-building AI assistant that communicates in friendly, human terms.

  1. Conversational UX Design

  • Designed chat flows and dialogue scripts clarifying score changes, on-time streaks, and utilization impact.

  • Applied tone guidelines rooted in trust + transparency, avoiding jargon.

  1. Prompt Engineering & System Logic

  • Built system prompts that generate contextual CTAs — e.g., “Your limit usage is 12%; learn how this affects your next boost.”

  • Linked credit events to actionable features (payments, dashboard, reports).


4. Prototype & Data Integration

  • Collaborated with data analysts and backend engineers to simulate live API connections.

  • Developed a working prototype using Framer + Firebase with mock credit data and user event logs.


5. Brand & Web Launch — TomoCredit.ai

  • Designed and shipped the Framer-built microsite within 2 days for PR and investor outreach.

  • Created landing-page visuals, typography, and animations aligning with Tomo’s trust-first identity.

  • Collaborated with leadership and marketing for unified product + brand messaging.
